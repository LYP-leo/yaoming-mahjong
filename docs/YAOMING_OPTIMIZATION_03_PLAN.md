## 1. 结算可解释性

- 默认展开赢家的完整终局手牌和副露（含暗杠），显著标出真实和牌实体；点和牌已由引擎放入赢家手牌，不得重复添加。
- 手牌旁逐项展示服务器结算的番型、每项番数、说明及原始总番/封顶后计番；不由前端重新推断分数。
- 保留三家点数、支付明细、其他玩家终局手牌、流局及确认后续局行为；无赢家/旧数据缺手牌时明确提示，不崩溃。
- 桌面并排、窄屏上下布局，长手牌局部滚动，不让结算按钮被挤出可访问区域。

## 2. 自动摸牌设置

- 新增可从大厅/牌桌访问的设置入口，自动摸牌默认开启、保存在本机，允许关闭恢复手动摸牌。
- 只在当前用户真实牌桌、已连接、非托管、非忙碌、本人轮到摸牌且服务器列出 DRAW 合法动作时发起；不自动出牌、响应或确认结算。
- 打开复盘/规则、离席确认、暂离或关闭组件时暂停自动动作并清理待执行任务。身份、房间、轮次/版本切换时防止旧任务提交。
- 与手动操作共用服务端版本和幂等保护；同一可摸状态不因轮询/SSE重复触发；失败显示错误并允许手动恢复，避免失败请求循环。

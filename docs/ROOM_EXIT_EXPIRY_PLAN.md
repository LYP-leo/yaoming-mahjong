# 等待房间直接退出与无人房间回收计划

日期：2026-09-12

## 用户要求与默认选择

- 等待中的房间可真正退出并立即释放座位，而不是只能暂离保留座位；进行中的牌局保留明确的暂离/离开语义。
- 机器人不算真人。默认无人保留10分钟后自动销毁，可由服务器配置修改。
- 真人主动退出立即不再计入；断线超过60秒视为不在房间，之后开始无人倒计时，短暂网络抖动不触发立即销毁。真人重连或有人加入取消倒计时。在线托管中的真人仍算真人。
- 计时独立于机器人动作及lastActivity，避免机器人永远刷新存活时间。重启兼容旧存档并保留重连宽限，不能重启即误删。
- 删除房间前按现有鉴权及容量限制归档已经结束的小局；历史结算不重算。不为中断的未完小局编造结算。

## 实施步骤

1. 明确等待房间主退出入口、释放座位提示；失败不清本地身份，成功才返回大厅，保留已有幂等与版本冲突重试。
2. 增加可持久化的无人起始时间及服务端可配置保留期；区分真人、机器人、已离席、离线真人。正确处理房主转移及空房重新加入。
3. 统一无人回收路径，处理等待/进行/结算中的房间；清理前归档已完成牌谱，断开推送并更新大厅。空等待房允许恢复，不因players为空被读档过滤。
4. 自动测试覆盖退出、重试、房主、空房复用、机器人不续命、重连取消、到期边界、重启及存储失败回滚；跑全量回归、构建与本地浏览器验收。
5. 写测试报告；按现有线上同步流程先备份、检查活跃房间再短暂停服发布，核验服务/接口/静态资源。

# 游戏滚动区域与听牌番数测试报告

日期：2026-09-09

## 实现与发现

- 手机对手牌河原高 80px，两行牌、4px 行间距和标记内边距共需 84px，会产生仅 4px 的纵向滚动。调整固定布局，手机三家牌河均预留 86px。
- 托管横幅、按钮及普通和牌提示约需 69px，原提示轨道仅 48px。轨道改为 72px，普通托管不再内部滚动。
- 手牌区为选牌抬起、牌底阴影和水平滚动条预留空间；桌面/手机轨道为 96/84px，玩家面板整体固定为 344/319px（手机另加安全区）。
- 手机快捷设置不再是仅 26px 高的横向滚动框；极窄屏隐藏重复的括号说明，保留复选框、名称、倒计时。
- 高度不超过 540px 的窄屏改用页面正常滚动，避免固定面板在 `60dvh` 临界点产生 1px 溢出。
- 听牌、牌局动态、日志和结算正文明确为纵向滚动；手牌、副露、动作、赢家手牌明确为横向滚动。设置/入座弹窗只保留内部纵向滚动；弹窗期间锁定背景，稳定滚动槽避免宽度跳动。
- 长房间名可换行；手机听牌卡占侧栏整行，避免番数被两列窄栏挤压。
- 听牌显示张数及后端有效番数：两种方式相同显示如 `4番`；不同显示如 `点和4番 / 自摸5番`；仅自摸有效时只显示 `自摸4番`。没有重算或更改后端规则。
- 显示差异键包含有效番数，番数变化更新文字而不重建相同牌面；无关版本、实体 ID、无效方式番数和原因文字不触发重绘。空听牌无文字，后台请求保留旧结果。

使用本地独立样例页及真实组件，不创建测试对局、不读取座位身份、不向生产发送游戏操作。尺寸以 DOM 实测 `innerWidth/innerHeight` 为准。

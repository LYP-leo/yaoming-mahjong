## 已知边界

- 新功能只作用于新版要命麻将。更新前没有记录的已结束旧局无法追溯；进行中旧快照续录会标为不完整。单局帧数超过保护上限也会标记不完整，保留结算。
- 归档是有上限的历史，不是永久云存储。复盘 JSON 暂不支持导入编辑；本批不是 AI 最优弃牌建议，也不会替玩家操作。
- 本批仍是单进程、全量原子 JSON 快照；未完成分房数据库、账号体系、HTTPS、长期高并发压力或故障集群测试。SSE 连接上限/慢消费者有单元覆盖，不等同于生产承载能力认证。
- 浏览器验收为桌面与两种模拟手机视口，未覆盖所有实体手机及移动网络；随机对局加定向测试不等同于所有可能牌型穷举。

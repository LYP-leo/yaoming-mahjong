# 要命麻将优化第一批计划 · 2026-09-07

## 范围

本批遵循上轮评审，优先解决在线挂机阻塞和基础操作体验。先写本计划再修改代码。保留现有 Java + Vue、规则计番、身份与幂等设计，旧版不作功能改动。听牌辅助、完整牌谱、实时推送/分房持久化、HTTPS/账号体系为后续批次，不在本批引入。

## 行为约定

1. 服务端权威计时：摸牌 15 秒、出牌 30 秒，吃碰和响应仍 20 秒。轮询、查看规则、重复提交、无效操作不得续时。超时对当前玩家开启“操作超时托管”，正常页面心跳不会自动取消；玩家主动取消托管时，若轮到自己则获得一次完整行动时限。
2. 局间结算最长 60 秒，超时仅代未确认玩家确认并继续轮庄；终场结算不自动退出。等待开局不强制准备。时限只影响节奏，不修改用牌、和牌和算点规则。
3. 时限及阶段保存在快照中；服务端采用可注入时钟测试。重启不凭心跳续时，逾期阶段按正常超时逻辑推进，不重放旧请求；持久化失败仍回滚。客户端按服务器时间校正倒计时。
4. 自己新摸的牌在右侧单独显示，包含补牌；出牌后归整，吃碰后没有摸牌区。服务端仅在自己的私有视图提供摸牌实体 ID，对手不可见。
5. 最新弃牌与供牌人可见；牌河用实体 ID 高亮当前最新一张，被吃碰杠或点和取走后不得保留虚假河牌。响应时明确显示响应的牌。
6. 默认两次点击确认出牌，第一次选中抬牌，第二次提交；也有明确“打出所选牌”按钮及可持久化的快捷出牌开关。切换轮次、摸牌/副露变化、进入托管或合法动作消失时清除陈旧选择；同一轮新版本心跳不能随意取消正常选择。网络提交未完成时禁止二次写入。
7. 手机牌桌采用紧凑双对手区、常驻手牌操作区；最新弃牌/阶段倒计时可见。390px/320px 不强制整桌 650px 横滚；保证可辨牌面和触控目标，需要时仅在明确局部区域滚动。桌面保持现有布局。

## 接口增量（旧客户端可忽略）

- PlayerView 增加 `drawnTileId: string|null`（仅本人）、`trusteeReason: 'MANUAL'|'OFFLINE'|'TIMEOUT'|null`。
- RoomView 增加 `serverTime: ISO string`、`deadlineKind: 'DRAW'|'DISCARD'|'REACTION'|'SETTLEMENT'|null`。
- 现有 `deadlineAt` 扩展为当前阶段权威截止时间。
- RoomView 增加 `lastDiscard: {tile:Tile,fromSeat:number,claimed:boolean}|null`，每局开始清除，被取走后 claimed=true。
- 计番和动作提交字段不变；接口/规则说明同步时限说明。

## 本轮发现并修复

1. 服务器原后端未运行：新增 systemd Java 服务，开机自启、异常自动重启，只监听本机。
2. 公网 Vite 开发服务器因异常 URL 将 `URI malformed` 遮罩广播给玩家：停用开发服务，现有 Nginx 提供 Vue 正式构建，FRP 仍转发前端 5173。
3. 非 HTTPS 公网环境可能缺少 `randomUUID`：使用 `getRandomValues` 后备实现。
4. 重连后保留旧 500 报错、网络提示英文：恢复同步时清理同源错误，保留业务错误，中文提示。
5. 多标签依赖共享身份导致可能串号：先固定 session 身份；暂离保留原座位且不影响另一标签。
6. 退出提交已生效但响应丢失：服务端保存有限期回执，客户端用同一请求编号重试；永久失效进入恢复页。
7. 副露来源不明确/加杠缺乏区别、重复吃牌选项：横牌与供牌来源、加杠叠牌、按牌型去重；河、副露、手牌独立区域。

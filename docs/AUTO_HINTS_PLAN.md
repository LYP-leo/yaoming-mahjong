# 自动听牌提示与剩余张数展示计划

日期：2026-09-09。本文在实现前记录。现已完成实现、自动化回归、浏览器验收和前端发布，详见 `AUTO_HINTS_TEST_REPORT.md`。后端未重启。

## 范围与计数口径

- 修改当前默认的要命麻将听牌辅助，不改牌面、规则、机器人或旧版自定义玩法。
- 后端已有 `unseenCount`：4 减本人手牌、所有玩家牌河和公开副露，同一实体 ID 只计一次，不读取其他人的暗牌或牌墙。假设打出的牌仍计入已知牌。继续使用该接口，不在前端另算一套。
- 数字表示尚未可见的张数，可能在对手手中，不是实际牌墙张数。保留 0 张的结构进张，并明确提示四张已知；不足起和番数的进张仍说明限制。

## 实现顺序

1. 验证现有后端的三张/四张公开牌、实体去重和隐私测试，必要时补充定向测试。
2. 听牌辅助默认展开；进入进行中的有效座位后自动请求；牌桌版本/身份变化后撤下过期结果，合并短时间连续更新后重新分析。相同版本的心跳不重复计算。收起仅隐藏显示，不影响后续自动更新。
3. 取消失效请求并用身份、版本和请求代次防止旧响应串入；离开页面/结算停止计算。短暂网络故障有限自动重试，身份失效不循环重试。响应版本超前时通知父页面同步，再自动重新分析。保留手动重试作为故障后备，不作为正常计算入口。
4. 每张等待牌下直接显示 `N张`，0 张使用清晰提示；打后听牌方案默认展示等待牌，不再要求逐项点击才可查看。
5. 组件自动化回归、后端计数定向回归、前端全套测试与构建；浏览器检查桌面/窄屏自动刷新及 0/1 张展示。测试数据只使用自建隔离房间或本地测试夹具。
6. 验证后备份并发布前端，检查公网资源及后端进程未变。本次无后端功能改动时不重启后端、不影响正在进行的牌局。完成后记录 `AUTO_HINTS_TEST_REPORT.md`，更新 README 使用说明。

## 重点测试

- 无点击初次计算、摸打/其他玩家公开动作后刷新、同版本心跳不重算、连续版本合并、收起后仍更新。
- 旧请求取消、乱序返回、身份/房间切换、卸载和结算后无请求，响应身份/版本不匹配时不显示旧数据。
- 临时网络错误有限重试，401/403/404 等不无限请求，可手动恢复。
- WAIT 和 DISCARD 两种模式均显示 0/1 张；死听不被隐藏，番数限制不被删除，计数不声称是实际牌墙数量。

# 游戏滚动区域与听牌番数修正计划

日期：2026-09-09

## 本次范围

1. 在真实浏览器检查牌桌、手牌、副露、牌河、操作区、提示区、侧栏、结算与复盘的滚动轴及溢出量。修正横向滚动引发的纵向滚动、固定轨道与边框/内边距不匹配等问题。不用全局隐藏滚动条掩盖内容丢失；长内容仍可用键盘、鼠标或触屏查看。
2. 听牌牌面下保留剩余可见信息，并显示后端给出的有效和牌番数。点和、自摸相同则合并为一个番数；不同时分别简洁标注，只显示允许的和牌方式。空听牌保持无文字，后台计算保持旧内容，番数变化才更新相应文字，不重建相同牌面。
3. 保持固定牌桌、手牌区和听牌侧栏高度；在窄屏及较矮视窗保留必要的内容访问方式。

## 实施顺序

- 保存修改前源代码备份；建立独立视觉场景，不连接真实对局。
- 并行处理听牌展示/更新测试与滚动区域审核；主线程负责浏览器几何测量、布局修正。
- 增加少量与极限内容、相同/不同番数、番数单独更新、手机和桌面尺寸的回归用例。
- 执行前端全部测试及生产构建，浏览器复核各滚动轴、稳定高度和结算可访问性。
- 只更新现有服务器前端，保留后端、正在进行的对局、牌谱及服务配置；如需后端改动另行记录。
- 完成测试报告，记录实际发现、通过结果、部署与限制。

## 验收

- 正常内容没有只可滚动几像素的多余滚动条；超长内容只在指定方向滚动。
- 手牌、摸切标记、加杠叠牌、最新弃牌、所有操作按钮不被裁掉。
- 每张有效听牌同时能看到张数和对应番数；点和/自摸不同不误报为一个相同数值。
- 请求中、相同结果返回不清空牌面；番数变化可正确更新，空结果无占位文案。
- 不修改算番规则、机器人策略、托管或牌面图案。

# 四人牌桌轻量压缩计划（2026-09-12）

## 范围

用户希望四人对局稍微降低各玩家区域和整页高度。本次只调整四人布局样式，不改规则、服务器对局逻辑、三人布局、牌面素材或键盘操作。

## 设计与约束

- 四人区域保持东南西北四行、本人黄框和所有人的牌背；优先收紧行内上下留白与行间距。
- 目标每行从 158px 减到约 146px，桌面总高从 672px 减到约 614px；具体以真实浏览器压力验证为准。
- 固定保留身份、两行状态、行动标记、计分、14 个暗牌位置、副露及牌河轨道。行动标记空白时仍占位，摸牌不推动副露。
- 不压缩牌面长宽比例、私有手牌、鸣牌按钮与听牌预留区域；不靠隐藏正文溢出、缩放整页或添加内部滚动条实现压缩。
- 仅在包含四人牌桌的对战/复盘页面略微收紧页顶和标题间距。手机保留现有导航高度与水平边距。

## 验证与交付

1. 修改前记录本地浏览器三人、四人桌面和手机布局尺寸。
2. 覆盖空/大量牌河、四组副露（含加杠）、行动玩家切换、摸牌/出牌、长提示、多鸣牌选项、听牌、空座与复盘。
3. 比较玩家、计分、副露、操作区的前后坐标，检查内容边界、牌面比例和新增滚动区域；确认三人尺寸不变。
4. 更新布局回归测试，运行前端全量测试、类型检查、资源校验和生产构建；写测试记录。
5. 校验线上版本并备份前端资源，仅发布前端（资源先行、入口最后），不重启后端、不打断对局；核对公网资源哈希。

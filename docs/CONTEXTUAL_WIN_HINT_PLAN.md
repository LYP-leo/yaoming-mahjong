# 和牌提示按场景显示（2026-09-12）

## 用户要求与范围

- 托管时不显示下方的规则说明、和牌资格提示及遗留的自动摸牌提示；保留托管状态与“收回控制”操作。
- 非托管时去掉常驻“3/4 番起和、8 番封顶、无振听……”规则摘要，也不再用前端通用规则文字填补空提示。
- 保留服务器给出的当前手牌判断、可自摸/点和与番数不足提示、吃碰后操作限制；听牌牌面、番数、剩余张数及增量更新机制不变。
- 三人、四人规则共用显示策略；不修改任何番值、和牌资格或托管出牌逻辑。

## 实现

在 TableView 的展示层过滤已知常驻规则摘要，托管/只读状态返回空提示。不存在可展示内容时不生成文字节点，但继续保留固定高度的提示容器，避免手牌/动作区/听牌区上下跳动。前后端协议不变，本次仅发布前端，无需停服。

## 验证

1. 新增三/四人、手动/离线/超时托管、摸牌前后、响应与可和、空提示和只读复盘的回归测试。
2. 复用听牌增量更新、自动摸牌、快捷键及固定布局全量测试；更新不再适用的常驻兜底文案断言。
3. 本地浏览器验证托管切换、摸打转换与听牌仍可显示，比较提示容器/手牌/操作区坐标不变。
4. 构建通过后记录测试结果，备份并发布前端，校验线上资源和后端进程未重启。

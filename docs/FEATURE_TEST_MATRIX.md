# 全功能测试矩阵

本轮结果：当前已实现功能除 U05 手机真实视口外均已通过自动化或浏览器验证。杠牌扩展、特殊末张和、一炮多响/截和、响应倒计时、超时自动过与响应托管均已纳入回归；U05 因本次浏览器视口覆盖未实际生效而保留人工回归。

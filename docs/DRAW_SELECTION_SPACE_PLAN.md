# 摸牌默认选中与空格出牌计划

2026-09-11，实施前记录。

1. 真人可出牌回合收到普通摸牌/杠后补牌后，按服务器 drawnTileId 默认选中该实体，只改变选择，不自动出牌。刷新/重新打开当前牌桌也恢复这一默认；A/D 或鼠标改选后，同状态心跳不会覆盖选择。
2. 出牌阶段 Space 与 Enter 均确认当前选中且合法的牌；响应阶段 Space 继续发送 PASS。二者共用单次提交锁，防止交替或长按重复发送。
3. 保留输入、弹窗、IME、托管、过期、忙碌和只读保护；焦点停在手牌时也确认当前选中牌，不触发浏览器按钮的第二次点击。吃碰后无摸牌、实体不匹配或无合法出牌时不随意选牌。
4. 增补键盘与组件测试，迁移“摸牌后清空选中”的旧断言；检查手动改选、补牌、心跳、无摸牌、只读、Space过牌等情况。浏览器实际按键验收、构建、记录测试文档，随后仅更新前端并核对公网。

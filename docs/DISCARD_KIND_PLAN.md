# 手切 / 摸切区分计划

日期：2026-09-09。本文件在本次编码前记录。

## 语义与实现

- 由服务器在弃牌成功时按实体 ID 判断：打出 `lastDrawnId` 为摸切（`TSUMOGIRI`）；打出其他手牌为手切（`TEDASHI`）。同牌型的不同实体不得混淆。吃碰后没有刚摸到的牌，弃牌为手切；杠后补摸按实际补摸实体判断。机器人和托管走同一判定。
- 不更改共用 Tile 及和牌规则。玩家弃牌记录另附实体 ID 到弃牌类型的映射，最新弃牌携带类型；公开视图和已结束牌谱包含这一公开信息，但不增加对手暗牌或摸牌实体泄露。
- 弃牌类型持久化、深复制到牌谱快照；被吃碰杠 / 和牌取走时最新弃牌仍保留类型，新局清空。历史数据缺失字段视为未知，不伪造手切 / 摸切。
- 三家牌河、最新弃牌、复盘使用同一弃牌组件。摸切牌下方加小横杠，手切不加；无论有无横杠，牌位占用空间一致。通过无障碍标签及悬停说明说明类型，避免新增动态文字影响刚修好的稳定布局。

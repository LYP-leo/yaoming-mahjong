# 要命麻将第二批计划 · 2026-09-07

编码前记录。本批实现听牌辅助、已结束小局牌谱复盘、鉴权实时推送，保留现有 Java/Vue 和规则，不引入新依赖或改动旧版玩法。

## 听牌辅助

- 私有、按需接口 `GET /api/yaoming/rooms/{id}/hints?playerId=...`，沿用 X-Resume-Token；响应带 roomId/playerId/version，前端丢弃陈旧结果。
- 13 张等效手牌列出进张；自己待出牌时按可打牌列出打后进张。复用真实计番器，区分结构完成、自摸/点和够番及舍牌/同巡限制；不自动代打。
- 数量标为“未知张数”，仅按本人手牌和公开牌扣除，不看对手暗牌、牌墙或牌墙顺序，也不承诺仍在牌墙。杠上炮等条件性加番不作为普通听牌资格。
- API 形状：`{roomId,playerId,version,analysis:{mode,waits,discards,note}}`；Wait `{tile,unseenCount,canTsumo,tsumoFan,canRon,ronFan,ronReason}`；Discard `{tile,waits}`；mode WAIT/DISCARD/UNAVAILABLE。本批固定要命规则，不扩展旧自定义番种。

## 牌谱复盘

- 从本次更新后的开局开始记录，保存初始发牌和每次动作后的牌桌帧（手牌、牌河、副露、点数、阶段和供牌来源），不保存恢复码或牌墙顺序到可导出文件。
- 仅本场参赛者可读取已结束小局的三家全视角；当前未结束小局不得通过列表、详情、推送或导出泄露。历史旧局无完整记录时明确说明，不伪造补齐。
- 提供牌谱列表、分局选择、上一步/下一步、首尾、滑块、自动播放和 JSON 导出；只读复盘不能提交游戏动作。复盘期间继续同步真实牌局，并提示对局仍在计时。
- 本轮持久化采用现有原子快照事务，牌谱与结算一并提交/回滚，已完成记录在离席/房间清理后仍可凭原座位身份查看；服务器最多保留最近 20 场已归档记录，前端保存本机自己的历史凭据。单局帧数保护上限 1024，触顶明确标记不完整。
- 接口：`GET /api/yaoming/replays?roomId=...&playerId=...` 返回一个授权房间的已完成小局摘要；`GET /api/yaoming/replays/{roomId}/{round}?playerId=...` 返回完整已完成小局；均要求 X-Resume-Token。

## 实时推送

- 采用 fetch + SSE 流 `GET /api/yaoming/rooms/{id}/stream?playerId=...`，令牌只放请求头，不放 URL。推送仅含 roomId/version/type，收到后拉取自己的裁剪快照。
- 成功落盘后才发布通知；失败回滚不得发布成功通知。包括机器人、超时、加入/退出等状态变化；鉴权失败不建立流，控制每人/全局连接数。
- 服务器定期心跳；前端自动重连、清理旧流，身份/房间切换与卸载时中止。健康推送时保留 10 秒安全同步，失败时 2 秒轮询兜底，不因开复盘或帮助停止牌局计时。
- Nginx 禁止缓冲 SSE；沿用 FRP 前端入口，不公开新端口。

## 验证与发布

- Java：提示与真实计番一致、159 万、4 番门槛、振听/可自摸、未知张数不读隐藏牌；复盘帧一致、旧快照兼容、鉴权与当前局禁止、离席后保留、回滚/重启；推送鉴权、内容隐私、落盘失败不通知、订阅清理。
- Vue：提示陈旧响应/错误恢复，复盘分页/边界/播放/导出/无游戏写操作，SSE 拆包解析/重连/降级/身份切换/清理。

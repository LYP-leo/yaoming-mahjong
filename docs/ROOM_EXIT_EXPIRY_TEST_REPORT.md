# 等待房间退出与无人回收：测试报告

日期：2026-09-12

## 实施结果

- 等待时提供直接“退出房间 · 返回大厅”，发送真正的LEAVE释放座位，不再把暂离作为并列主入口。失败保留身份及错误；对局中的退出仍有确认。
- 已暂离的大厅横幅新增“退出原房间”；使用原身份读取最新版本再提交，网络重试沿用请求ID、409最多三次，不恢复或覆盖当前身份，不误清其他标签页恢复数据。失效记录须用户明确清除。
- `YmRoom.emptySince`持久化无人起始时间。真人主动退出立即不算真人；60秒无心跳算离线，之后默认无人保留600000毫秒。机器人/已离席不算真人，在线托管算真人。机器人活动不刷新计时；无人时暂停牌局推进，仍如实标记离线状态。
- 重新加入空等待房或在到期前重连取消计时，新真人接任失效房主。到期在定时任务、查询/加入/恢复入口检查，不能利用两次定时检查之间的空隙复活过期房。
- 旧真人房重启有60秒重连宽限，已有无人计时不重置。等待状态的零玩家存档也可恢复。
- 清理前仅归档已完成的小局，保持历史结果和身份鉴权，沿用最近20场上限；未完成小局不编造结算。销毁及归档一起持久化，失败回滚；成功落盘后才关闭推送。

配置：`mahjong.rooms.empty-retention-ms`，环境变量 `MAHJONG_EMPTY_ROOM_RETENTION_MS`，默认600000毫秒且须大于0。计划见 `ROOM_EXIT_EXPIRY_PLAN.md`。

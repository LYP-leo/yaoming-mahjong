# 四人实验版改为3番起和：实施计划

日期：2026-09-12

## 范围

根据刚完成四人实验版后用户提出的“改一下规则，3番起和”，本次仅将四人实验版起和门槛由4番降为3番；三人版仍4番起和，两版均8番封顶。规则ID、牌组、各番种番数、支付倍率与历史已完成结算保持不变。

## 实施顺序

1. 以房间规则作为起和番数的唯一后端依据，贯通和牌资格、操作错误、听牌提示、规则说明及机器人策略。
2. 四人全不靠2番本身不能和，加不求人或杠上炮至3番可以和；恢复机器人的全不靠候选路线，禁止额外叠门清。
3. 更新前端大厅、规则页、桌边说明和默认提示；三人文案及行为保持4番。
4. 增加3番成功/2番失败、全不靠、点和/自摸、听牌、机器人及三人回归用例，运行前后端全量测试和构建，记录实际结果。
5. 延续用户已确认的线上同步发布流程，发布前检查房间状态、备份程序/房间/牌谱，短暂停服更新并核验公网接口及资源。若出现新的活跃对局，先报告影响再决定重启。

## 风险与验证

- 不修改已保存的历史计番和支付，不重算旧牌谱；当前四人房间恢复后采用新门槛。
- 不以实际入座人数猜测规则；未知规则仍拒绝。
- 保持原有番种排除关系和8番封顶，区分手牌结构成立与达到门槛。
- 不为当前范围之外的赛事积分或其他麻将规则添加假设。

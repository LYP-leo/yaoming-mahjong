# GitHub 首次上传计划

## 用户要求

- 新建 `yaoming-mahjong` 仓库，设为私有。
- 上传当前已完成的 Java + Vue 要命麻将项目，不影响现有服务器或对局。

## 顺序与保护

1. 确认当前 GitHub 认证账号，检查同名仓库是否存在；不得覆盖已有仓库内容。
2. 审查上传清单和第三方许可，排除运行数据、恢复码、日志、构建产物、依赖、临时测试备份、旧截图归档和本机私有凭据。
3. 完善忽略规则并更新 README 中过时的听牌说明；不修改游戏业务代码。
4. 初始化本地 Git，检查暂存区文件、体积及敏感信息后建立首次提交。
5. 在当前认证的个人账号中新建私有仓库并正常推送，不强制推送。
6. 验证远端可见性、默认分支及提交一致性，记录检查结果，提供仓库链接。

## 验证

- 无 `node_modules`、`target`、`dist`、游戏数据、密钥及本地备份进入提交。
- 牌面源素材、图集生成脚本、必要生成资源及上游许可均保留。
- 上传后远端为私有，提交 SHA 与本地一致；线上服务不变。
- 只调整版本管理与说明文档时不重复宣称已执行业务回归；上一次游戏测试记录仍单独保留。

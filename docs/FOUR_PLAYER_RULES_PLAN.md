## 规则差异

| 项目 | 三人版（保留） | 四人实验版 |
| --- | --- | --- |
| 人数与牌组 | 3 人，108 张，万只有 1/5/9，无北 | 4 人，136 张，标准 34 种，每种 4 张 |
| 万子顺子 | 159 特殊顺子 | 正常连续三张，不允许 159 特殊顺子/特殊连续数值 |
| 场次 | 东南各三局，共六局 | 东南各四局，共八局，南四结束 |
| 点和/自摸 | 点和 3n，自摸两家各 n | 点和 4n，自摸三家各 n |
| 门清 | 2 番 | 1 番 |
| 特殊和牌形 | 风龙 3 番 | 取消风龙；全不靠 2 番 |
| 全不靠 | 不支持 | 三种花色分别 147/258/369 加七字共 16 种，任意 14 种不重复；门清限定，仅加不求人/杠上炮 |

其他番种沿用已确认的三人最新版定义；包括无振听、九数齐不含字牌、暗杠保持门清、支付最多至零。均从 10 点起步，任一家归零结束，沿用剩余点数排名；文档没有给出赛事积分公式，不臆造积分。

## 实现顺序与边界

1. 增加不可变规则配置，以 `yaoming-3p` 和 `yaoming-4p` 区分，创建后房间规则固定。旧请求/旧存档/旧牌谱缺字段时只默认三人；未知规则拒绝。
2. 参数化牌组、顺子、计番、向听、机器人和听牌候选；所有入口依据房间规则，不能混用跨规则缓存。北风必须是风牌，不是箭牌。保留三人全部现有断言。
3. 参数化座次、发牌、开门、轮庄、鸣牌优先级、支付、总局数与恢复/复盘。房间视图、大厅摘要、牌谱保存规则身份，历史结算不重新计算。
4. 创建弹窗可选择两套命名规则，并查看对应详情。大厅显示人数与规则；三人/四人牌桌固定东南西/东南西北，上方自己仍显示牌背且黄框，下方手牌和快捷键不变。
5. 桌面轨道按人数固定，不因摸牌、副露、行动标签或听牌产生抖动。复盘复用对战布局并按历史规则显示四家与鸣牌来源。
6. 执行正反例、精确 4 番边界、支付截零、北家行动/鸣牌/轮庄、混合房间/存档/牌谱/隐私、机器人、听牌自动更新，以及所有已有前后端测试和生产构建。运行隔离 HTTP 全流程和浏览器 3/4 人界面检查，完成后写测试报告。

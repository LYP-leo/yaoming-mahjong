# 智能机器人升级测试报告

日期：2026-09-09。编码前计划：`SMART_BOTS_PLAN.md`。

## 已实现

- `YmShanten`：标准四面子雀头结构距离、唯一 159 万顺子/搭子、精确风龙目标；不添加七对子分支。分花色轮廓与整手缓存均有上限，按次决策复用，输入不变。
- `YmBotObservation`：从服务锁内提取本人手牌/副露/振听信息及公开牌、公开副露数、点数和剩余张数。纯策略不接收 room，不读取对手暗牌/恢复凭据/响应或牌墙内容。该玩法暗杠公开牌型、露中两张，所以四张数量是公开可知；此结论不能照搬到全背隐藏暗杠的其他规则。
- `YmBots`：合法和牌优先；选择更近的有效牌形、更多可用进张和番型前景；结构听牌但不够 4 番或四张全可见时不视为有效听牌。真实可和等待交给既有 `YmScoring`，不算普通和牌中不存在的杠上炮。
- 吃碰模拟对应副露及后续弃牌，与过牌比较；开门要求有够番前景，不再一律拒吃碰或见副露就吃碰。暗杠仍保门清，所有杠比较牌形/番数收益；补牌前结构估计不读取补牌实体。杠的模拟会清除临时过牌限制，永久弃牌限制仍保留。
- 同等牌效下参考对手公开牌河和两组以上公开副露的危险程度；低分远离听牌时适当避险。公开牌河中的同种弃牌受本玩法禁止点和规则保护，其余风险只是估计，不能推断对手真实听牌。
- 机器人、主动托管、离席接管、超时即时动作均接入新决策；只输出状态机已有合法动作。异常时回退到合法过牌/弃牌，不记录私有手牌或凭据。
- 未修改前端、规则、API 格式、数据字段、650 ms 节奏、FRP 或 Nginx。

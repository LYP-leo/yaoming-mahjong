## 实施顺序

1. 独立审计规则引擎/听牌/机器人/恢复/牌谱，以及前端所有规则展示。
2. 更新纯计番器，按新定义补正反例和恰好 4 番边界，调整旧规则断言。
3. 更新规则 API、规则手册和当前 README，保留历史计划/测试报告作为历史记录。
4. 验证合法和牌动作、听牌番数、实际支付、机器人决策全部经过新版评估；旧牌谱与已完成结算保留当时快照，不按新规则重算。
5. 执行全部后端/前端测试和构建，运行隔离 HTTP 测试与本地浏览器检查。
6. 备份后发布前后端。检查运行房间恢复时的旧响应缓存，必要时按新规则刷新；不删除房间或牌谱。记录实际部署、测试结果和验证限制。

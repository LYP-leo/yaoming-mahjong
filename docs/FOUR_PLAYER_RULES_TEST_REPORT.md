## 新规则与回归覆盖

- 136 张、34 种，每种四个独立实体，无红牌；原三人 108 张不变。所有普通万子顺子正例，159 万在四人版被拒绝，在三人版仍有效；北牌仅四人牌组允许。
- 四人所有 20 个番种的正例、否定条件与排除关系；北是风牌不是箭牌，北家门风正确。四人门清 1 番，三人门清 2 番。
- 全不靠六种花色分配、每组16种选14种，共720种组合；逐张移除后的向听与等待，重复牌/错误花色/副露否定；只计2～3番，不能误加门清凑到4番。四人不认可风龙。
- 向听使用两段17位五进制缓存，覆盖34种高位、缓存隔离及有界性；200副标准完整牌和候选性能测试。机器人使用房间规则，保留普通万顺，不追逐无法达到4番的全不靠路线。
- 四家人齐准备、每家13张、84张余墙、正确开门/切墙、北到东轮转与吃牌、多人点和截和、杠与托管原回归、四家确认后轮庄、南四终场。
- 点和4n及支付截零、自摸另外三家各n、40点守恒；三人点和3n/两家自摸与30点守恒仍通过。
- 听牌按规则枚举，包含新增万子与北；未知张数1/0、番数、只扣自身和公开牌、不读取对手暗牌或墙顺序、14张打后听牌不修改原手牌。
- 两种房间并存，未知规则创建/读取拒绝，房间固定规则与容量；旧无规则存档/牌谱默认三人，不凭当前入座人数猜规则。持久化失败回滚、四人离席归档恢复、鉴权、旧结算保留、进行中牌谱不公开。

本地预览 `stable-table-preview.html`：三人基础轨道保持原样，四人桌面总高672px、手机662px，四行均158px。切换空/大量牌河（每家60张视觉压力样例）、四组副露、长提示、多动作时，四行位置和总高不变；摸牌/出牌及行动玩家切换后几何信息一致。桌面及手机未发现新增细小内部纵向滚动容器；牌河单行、北位本人黄框与牌背正确。窄屏完整手牌滑动、完整牌河/详情对话框属于有意保留的正常查看区域。

在实际本地四人房间添加三名练习机器人并开始对局：136张发牌，其他玩家手牌仍隐藏，自己的摸牌自动选中；空格提交后牌河有摸切标记，机器人完成一圈后自动收到下一张摸牌，无浏览器控制台错误。

生产构建预览恢复隔离的四人点和终局：赢家14张牌包含唯一和牌标记；列出门清1番、清一色3番与总4番，四家分数齐全，应付16点但余额10点只支付10点。进入真实牌谱API返回的记录后有四家历史牌面；在牌桌区域滚轮使1/4步变2/4步，页面滚动位置保持不变。旧局迁移缺失起始步骤时仍如实标记记录不完整。

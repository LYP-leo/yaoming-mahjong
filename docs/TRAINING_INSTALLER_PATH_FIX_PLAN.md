# Windows 训练安装器多 Python 路径修复计划

日期：2026-09-12

## 问题与范围

用户在激活 `yaoming-python` 后运行安装器，错误消息把 Conda 环境、Conda 根目录和 WindowsApps 的三个 Python 路径拼接成一条命令。安装器使用 `Get-Command -CommandType Application` 查询程序；查询可能返回多个结果，直接读取 `.Source` 得到数组，传入字符串参数后被空格连接。

只修复离线训练包的程序路径解析，不修改游戏规则、线上服务、全局 Python 或已有虚拟环境。

## 实施步骤

1. 用单一解析函数按 PowerShell/PATH 顺序选取第一个应用程序，确保返回一个路径字符串；Python、Java 和两个命令执行辅助函数统一使用。
2. 在 Windows PowerShell 5.1 下重现多 Python 命中，覆盖路径含空格、显式指定解释器、多 Java 命中、非零退出码和 stderr 处理；测试不得安装依赖或修改用户环境。
3. 文档补充此错误原因、完整解释器路径的临时绕过命令和重新运行方式。
4. 运行回归测试，记录实际结果，发布新的训练包（保留旧压缩包），并提供可单独替换的安装脚本。

## 验收条件

- 多个 Python/Java 位于 PATH 时仅调用优先级最高的一个，显式路径不被覆盖。
- 包含空格的单一路径可正常调用；原有错误退出、虚拟环境保护逻辑保持不变。
- 自动化测试通过并记录；无需删除环境、重装 Conda 或调整全局 PATH。

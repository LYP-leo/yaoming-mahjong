# 纯摸切托管与最新弃牌滚动条修正计划

日期：2026-09-09。编码前记录。

## 本次范围

1. 用户红框对应中央最新弃牌条。现有定高 44px 容器使用 overflow:auto，内容尺寸 / 牌影超出会产生竖向滚动条。改为不滚动的紧凑固定布局，限制文字到单行、省略长昵称但保留完整可访问名称；牌面与摸切横杠完整显示，整体高度不变。牌河、日志等真正需要滚动的区域保持原样。
2. 将真人托管与智能机器人策略分开。主动、超时、离线托管使用自动摸牌→打出刚摸到的实体；响应一律过，不吃碰杠、不自动和牌。取消托管后不继续执行先前计划。练习机器人以及明确离席后既有的机器人接管仍沿用智能策略。
3. 若玩家在吃碰后、没有刚摸牌的状态开启托管，必须合法出一张牌才能继续：固定选择按手牌排序的最右一张，不进行智能选牌；该张如实记为手切，后续恢复摸切。正常摸牌和杠后补摸严格使用实体 ID，不能用同牌型替代。
4. 不更改和牌计番、牌面素材、既有摸切记录、房间生命周期或真人准备 / 结算意图。保留当前等待 / 局间行为，必要文案明确“托管自动摸切”而不是泛称机器人代打。

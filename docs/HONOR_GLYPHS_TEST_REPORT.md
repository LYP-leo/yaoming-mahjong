# 字牌传统字形重绘测试报告 · 2026-09-08

## 实施范围

按照编码前 [字牌重绘计划](HONOR_GLYPHS_PLAN.md)，仅重绘東、南、西、北、中、發。此前风龙相关任务已经取消，本轮未恢复，不修改规则、判定、提示或后端。

六字使用独立闭合贝塞尔笔画，调整提按粗细、圆润转折、撇捺与内框留白。字牌略加宽，使笔画更舒展；黑风牌、红中、绿發保持原配色。浅色外缘先整组绘制，再叠加完整墨迹层，避免逐笔描边在笔画交叉处造成白色断口。目检后微调墨迹厚度和外缘，增强小牌辨识。

没有裁图、自动描摹、位图、系统字体依赖或数字/字母角标。目标是接近参考牌面的传统风格与可辨识结构，不宣称与图片像素完全一致。

# 操作、稳定布局与同桌复盘改进计划

日期：2026-09-11；实施前记录。按用户本轮截图与要求修改，规则和后端不变。

1. 删除所有操作区左右导航按钮和选牌后的冗余说明。操作区改为手牌下方全宽，鸣牌选项自动平铺/换行，不横向滚动。
2. 牌河改为单行。使用固定容量的单行预览与完整牌河入口，小屏等比例布局，不因张数增加换行或增高。
3. 公共手牌、摸牌空位和副露使用独立固定轨道；行动状态保留固定空间，分数绝不跟随行动提示移动。排查本人手牌、侧栏、听牌和操作区的相同问题。
4. 牌谱使用与对战共用的 TableView / PlayerLane 布局，在只读模式显示历史牌面，支持选择查看视角；继续只加载已结束小局，不生成实时操作。
5. 牌谱区域滚轮上下切换前后步；保护表单、弹窗、缩放手势和横向滚动，限制触控板连续滚动过快，切步暂停播放。
6. 对战快捷键：A/D 按显示顺序切换选牌（包含独立摸牌），Enter 提交合法出牌，响应阶段空格发送合法 PASS。只在当前活跃牌桌启用；输入框、弹窗、复盘、忙碌、托管、过期、组合输入或重复按键不误操作。
7. 增加组件和应用测试、像素级前后坐标对比、真实构建浏览器验收，记录问题与修复。测试通过后仅发布前端，保留服务器后端进程与牌局数据，并核对公网哈希。

验收重点：无 .ym-actions-scroll 按钮；多鸣牌无需横向导航；所有牌河处于同一行；摸打/行动切换前后副露、分数坐标不变；复盘只读且滚轮可切步；快捷键严格复用服务器动作，不绕过合法性与确认。

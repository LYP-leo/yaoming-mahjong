## 实现口径

- 服务器按弃牌实体 ID 与出牌前 `lastDrawnId` 比较，分别记录 `TSUMOGIRI` / `TEDASHI`。同图案不同实体不会混淆；不改用牌、计番、机器人选牌策略或现用上游牌面。
- `Player.discardKinds` 只标记当前牌河实体，`LastDiscard.kind` 单独保留最新弃牌类型。吃碰杠、点和取走后从牌河映射移除，但最新弃牌和历史帧仍保留；新局清空，不修改旧帧。
- 类型随房间持久化，三家私有视图共享已公开的弃牌类型；不会公开对手暗牌或尚未打出的摸牌实体。旧对象 / 数组快照缺少字段或显式 null 时按未知恢复，不猜测历史。
- `DiscardTile.vue` 为三家牌河、中央最新弃牌和复盘提供同一渲染：摸切下方 2px 短横杠，手切无横杠，悬停和无障碍标签说明类型。手牌、副露和听牌不使用此标记。导出牌谱只保留公开实体与合法枚举。

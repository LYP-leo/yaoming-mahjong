# 入座弹窗外部点击关闭修复计划

日期：2026-09-11

## 范围与目标

- 修复创建房间时点击窗口外空白区域不能关闭的问题。
- 创建、加入、恢复座位使用同一个入座表单；保持三种模式一致。
- 点击表单、输入框、标题及表单内空白区域不得误关；原有关闭按钮与提交保持可用。
- 不修改麻将规则、后端接口、对局状态或其他需明确确认的弹窗。

## 实施与验证

1. 检查现有 `@click.self`、遮罩布局与实际命中区域，复现问题并确认根因。
2. 最小范围修正遮罩/关闭事件，补充真实 Vue 组件交互及必要的布局回归测试。
3. 执行相关测试、全量前端测试及生产构建；使用可用浏览器验证窗口内外点击。
4. 记录实际通过结果、浏览器验证限制及发布状态。若更新已部署前端，只替换静态资源，不重启后端、不影响对局。

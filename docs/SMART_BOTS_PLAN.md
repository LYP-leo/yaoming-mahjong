# 要命麻将机器人决策升级计划

日期：2026-09-09。本文在实现前记录。现已完成实现、本地/服务器测试、隔离 HTTP 验证和线上后端发布，详见 `SMART_BOTS_TEST_REPORT.md`；本地旧 8080 调试进程未切换。

## 现状与范围

现有机器人已会执行合法和牌和杠牌，但出牌只按相邻/重复牌加权，门清时一律不吃碰，已开门后按固定顺序吃碰杠。缺少向听、有效进张、4 番门槛和公开牌风险判断。此次升级默认首页的要命麻将机器人，以及使用同一逻辑的托管/离席接管；不修改界面、牌面、旧版自定义玩法或和牌规则。

## 实施设计

1. 增加纯函数牌效分析：四面子一雀头的标准向听，支持 159 万特殊顺子；风龙使用六字牌+两顺子+雀头目标集合，不误用七对子和国士规则。单次决策共享缓存，并测量运行时间。
2. 在服务端把本人手牌/副露、本人振听信息、桌面可见牌和剩余张数转换为不可变决策输入。策略不接受整个房间、不读取对手暗牌、牌墙内容、恢复令牌或其他玩家响应。
3. 出牌先衡量距离成牌和真实 4 番可和进张，再比较扣除已知牌后的有效进张、牌型潜力及公开风险。用正式计番器判断临近和牌，不把结构成牌或零剩余张数误当有效听牌。
4. 合法和牌始终优先。逐项模拟吃/碰及其后续最佳出牌，与过牌比较，避免无条件破坏门清或接受没有够番前景的副露。杠牌也比较结构与番数收益，不再逢杠必杠；补牌只按未知牌分布或补牌前结构估计，不查看牌墙末尾。
5. 加入有限防守：依据对手公开副露及牌河做风险启发，优先同等牌效下的安全弃牌；低分、远离听牌且对手已多次副露时适当避险。不能据此宣称能判断对手真实听牌或绝对安全。
6. 全部输出仍必须取自状态机给出的合法动作。策略异常保守退回合法过牌/弃牌，不让评估异常卡住全局调度；日志不记录手牌或凭据。保留版本校验、实体牌 ID、650ms 机器人节奏、结算确认与持久化机制，不增加对外接口或持久化字段。

## 验证门槛

- 标准/159万/风龙向听和计番门槛定向测试，防止七对子误判、死听/第五张误算。
- 智能出牌、吃碰选择、合理过牌、杠牌取舍、和牌优先、公开危险信息及平局稳定性测试。
- 改换对手手牌、牌墙顺序和隐私字段后决策不变；输入不可变、暗牌不可读取、只从合法动作输出。
- 原有后端全套回归、多个随机种子整场机器人对战（108 张实体守恒、30 点守恒、4 番门槛、无卡死）、决策耗时记录。
- 用旧策略作为测试基线比较固定种子的有效和牌/流局情况；不将少量样本或启发式算法称为专业 AI。
- 在隔离端口/临时数据目录进行 HTTP 机器人房间烟测，不使用真实玩家房间。
- 测试通过后备份并更新服务器后端。发布前先读房间列表；若存在进行中的真人牌局，不擅自打断，报告待安全发布。前端静态文件不变。

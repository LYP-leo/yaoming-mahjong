# 新参考图直接截取牌面计划 · 2026-09-08

## 用户要求与范围

用户明确改为从新上传的图片直接截取，不再重绘。替换全部 34 种标准牌：万、筒、索各九种，東南西北中發白七种字牌。使用新图的白板（纯白），不保留旧框形白板。游戏逻辑、房间、计分、后端和网络配置不修改。

## 实施顺序（编码前）

1. 将用户提供的 2224×759 原图原样保存到项目资产目录，保留源图像素与校验值（聊天显示的缩略图不是原始尺寸）。按每张牌的实际矩形定义裁切坐标，特别核对右侧字牌顺序：上排東南西北，下排白發中。
2. 在共享 MahjongTileFace 中用 SVG 裁切窗口直接显示原图，不调用 AI 生成，不手画新图，不加字母或数字。完整保留牌面及蓝色牌边，使用圆角裁切去除外部桌布；保持比例，不拉伸字形。
3. 新旧前端统一使用该组件，手牌、弃牌、副露、结算、听牌、复盘和规则预览同步换图。牌背不请求或暴露具体牌面。未知牌仍显示安全占位。
4. 保留旧版自定义规则的红宝牌辨识能力：仅对牌面内部图案着红，不改牌边、不增加角标；普通 34 种牌必须直接使用原图。原图不包含红五，红宝牌是兼容变体，不称其为原图已有牌。
5. 更新美术断言，不弱化暗牌隐私、实体标识、结算和操作等回归断言。新增 34 张裁切完整性、字牌映射、边界、无角标、资源本地化、红牌与暗牌测试。
6. 用本地预览页检查全套、7 筒、7 索、七种字牌以及大小牌、横向副露和选中状态；运行全部前端测试与生产构建，记录测试报告。
7. 服务器发布前备份本轮相关前端文件和产物。服务器重复测试构建，只更新前端，保留旧哈希资源；核对公网资源与构建一致，验证页面能打开，后端 PID 不变。

## 验收边界

此素材本身是截图，放大清晰度受原图限制；不通过生成或描摹伪造高清细节。裁切不得包含图中说明文字、邻牌或绿色桌布。开发预览不进入正式构建。

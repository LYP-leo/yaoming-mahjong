# 入座弹窗外部点击关闭测试报告

## 发现与修复

- 原版已有 `@click.self`，普通遮罩点击在组件测试中可关闭，不能将用户遇到的问题笼统归因于“没有关闭事件”。
- 已确认的边界：原来的监听仅处理遮罩本身，不能处理由外部提示层截获的点击；错误条层级 60 高于遮罩 50。原版从输入框拖选到遮罩释放还会误关。
- 改为 document 捕获阶段判断事件路径是否位于入座表单外。外部点击关闭并阻止点击穿透；表单内部点击、内部开始的拖选均保留窗口。

- 组件卸载移除监听；保留输入、关闭按钮、校验与提交行为。

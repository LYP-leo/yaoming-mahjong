# 玩家纵向分区正式实施计划

日期：2026-09-11。依据用户已确认的 player-lanes-layout 样稿及最后两轮修订。

## 范围与不变量

- 正式三人牌桌使用东、南、西固定风位顺序。本人区域金色边框与当前行动者独立。
- 三家均显示 handSize 对应的牌背，包含本人；牌背长宽比为 19:26。真实手牌仅在底部本人操作区显示。
- 每家身份、分数、状态、暗牌背、副露、牌河在同一横向分区；本人副露/牌河不重复。
- 删除“场上玩家 3”和“手牌在下方”占位提示。牌面图集、三人规则、后端 API 不变。
- 底部独立手牌及摸牌、听牌辅助、合法动作；局况/最新弃牌/日志/恢复与复盘在侧栏。
- 长河通过显式完整牌河弹窗查看；默认分区高度稳定，无狭小内滚动条。小屏正常页面滚动，不遮挡操作区。
- 保留服务端合法动作、物理摸牌 ID、手切/摸切标识、结算、暗杠隐私、听牌保留更新、自动摸牌暂停与错误处理。

## 实施顺序

1. 拆出可复用公共玩家分区与信息栏；主牌桌负责手牌与动作，不增加游戏规则。
2. 接入真实 RoomView，按风位排序，集成固定听牌区域与可访问的详情弹窗。
3. 更新布局验收样例与结构性回归测试，增加换庄/本人换位/牌背数量/长河/隐私/弹窗覆盖。
4. 执行完整前端测试、类型检查和生产构建；浏览器检查桌面、窄屏和内容压力场景，使用隔离对局验证实际动作。
5. 记录测试结果后仅部署前端，保留服务器后端进程、进行中房间和既有哈希资源；核对公网产物哈希。

## 验收

- 东南西顺序不随轮到谁改变，换庄后仍按新的风位排布；金框只认 meId。
- 三家牌背数量来自公开 handSize，隐私牌面不出现在对方分区。
- 摸牌/出牌/吃碰杠/托管/结算入口继续发送原始服务端动作。
- 提示更新不清空重建相同内容；空提示无字，剩余张数和可用番数保留。
- 长河/四副露/长昵称/长提示不会覆盖别家、改变桌面分区高度或产生页面横向溢出。
- 前端发布前后 backend PID、JAR 哈希不变；失败保留旧入口可回滚。

# 3060 Ti 8GB 要命麻将训练包计划

日期：2026-09-12。用户要求提供可复制到另一台机器执行的环境安装方法与训练代码。

## 范围与约束

- 面向 Windows + NVIDIA RTX 3060 Ti 的 8GB 独立显存；共享 GPU 内存不计入显存预算。
- 提供独立离线训练目录、环境搭建脚本、CPU/CUDA 检查、小模型 PPO、自我对弈、规则机器人评估、断点续训及可携带压缩包。
- 复用本项目 Java 规则引擎，不另外编写一套简化麻将规则；三人四人分别训练，保留目前各自起和门槛。
- 不启动网页、不连接线上服务、不改动房间、不部署模型，不覆盖已有工作区改动。
- 训练包中的无界面适配器只移除牌谱记录等非规则开销。规则源码快照及哈希随包保存，训练与评估均使用它。
- 这是可训练的研究基线，不交付已达到某棋力的权重，不承诺几天超过现有机器人。

## 实现步骤

1. 明确 JSON 行协议、合法动作编码和仅限玩家可见信息的观测；创建有界、可复现、批量 Java 对局模拟器。
2. 创建 Python 环境桥接、小型策略/价值网络、合法动作掩码 PPO、冻结对手自我对弈、日志与模型检查点。
3. 创建设备自检、Windows 安装说明与脚本、构建/打包工具；显存默认按 8GB 保守配置，缓冲区放系统内存。
4. 独立检查未知牌不泄露、动作合法性、三四人规则、完整对局结算、终止处理、GAE/奖励归属、保存/加载/续训及版本不兼容拒绝。
5. 本机 CPU 跑通安装依赖、Java 编译、自动测试、短训练、评估与续训；记录 CUDA 未实测的边界。
6. 整理中文使用文档、实际测试报告，制作不含凭据、生产房间、个人路径或训练依赖环境的可携带 ZIP。

## 验收

- 在没有原项目源码目录的解压目录中，能够启动随包 Java 模拟器并执行短训练与评估。
- 三人、四人均能走到终局，牌数和分数守恒；策略无法选择非法动作。
- 一个训练样本对应同一学习玩家的相邻有效决策，不把别人的下一回合误当成本人的价值状态。
- 日志包含样本数、训练损失、回报、实际吞吐；保存模型、优化器、配置、规则标识和随机状态。
- 安装流程检查 Python、Java 21、PyTorch/CUDA，CPU 测试路径可运行；不声称当前机器验证过 3060 Ti 显存占用。

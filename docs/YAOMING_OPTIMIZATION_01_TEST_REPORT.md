## 本轮发现并修复

1. 带非法 tileIds 的托管命令可能续时：加强参数和终场校验，并回归验证拒绝时不改变状态/时限。
2. 倒计时组件在离线后重新挂载可能按旧快照重新校时：在网络接收点记录客户端接收时刻；同版本旧服务器时间不覆盖新视图，伪造同名字段被覆盖；重新挂载不延长期限。
3. 机器人快速推进时收回控制/确认离开碰到 409：仅对这两类意图执行最多 3 次有界重试；托管按预期最终状态判断，已经达成不重复切换；房间/玩家/令牌或请求代次变化立即停止。网络不确定重试仍复用原 requestId。
4. 320px 页面继承旧版 body min-width 产生额外横滚：新版挂载时限定解除，卸载时恢复，避免更改旧版。
